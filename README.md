# music-visualizer

![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=flat-square&logo=typescript&logoColor=white) ![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB) ![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white)

> Real-time audio visualizer using the Web Audio API

## Features
- 🎵 Load any MP3, WAV, or OGG file from your device
- 📊 3 visualization modes: Bars, Waveform, Circle
- 🎨 Customizable color picker
- ⚡ Built on the Web Audio API — no server needed

## Tech Stack
`React 18` · `TypeScript` · `Web Audio API` · `Canvas API` · `Vite`

## Quick Start
```bash
npm install && npm run dev
```
